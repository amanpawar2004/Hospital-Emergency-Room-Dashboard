## 📌 Overview
This project presents a **portfolio-grade, interactive Excel dashboard** designed to analyze Emergency Room (ER) data and improve operational efficiency.

It focuses on identifying **patient flow patterns, wait-time bottlenecks, and service performance metrics** to support data-driven healthcare decisions.

---

## 🚀 Key Business Questions Answered

- How many patients visit the ER over time?
- What is the **average wait time**, and where are delays happening?
- What % of patients are treated **within 30 minutes**?
- How many patients are **admitted vs not admitted**?
- Which **age group and gender** contribute most to ER visits?
- Which departments receive the highest **referrals**?

---

## 📊 Key Insights

- 📈 Patient volume trends help forecast demand  
- ⏱️ Wait time analysis identifies operational inefficiencies  
- 🏥 Admission patterns highlight hospital capacity usage  
- 👥 Demographic insights support targeted healthcare planning  
- 🔁 Department referrals assist in resource allocation  

---

## 🛠️ Tech Stack

- **Excel**
  - Power Query → ETL (Extract, Transform, Load)
  - Power Pivot → Data Modeling
  - DAX → KPI Calculations
  - Pivot Tables → Analysis
  - Charts & Slicers → Interactive Dashboard

---

## ⚙️ Dashboard Features

- 📅 **Dynamic Slicers** (Month & Year)
- 📊 **KPI Cards** (Patients, Wait Time, Satisfaction)
- ⏱️ **Performance Metrics** (On-time vs Delayed Cases)
- 👥 **Demographic Breakdown** (Age & Gender)
- 🏥 **Department-wise Analysis**
- 🔍 Fully **interactive and user-friendly design**
